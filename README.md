# German Football Ground Explorer

An interactive map and groundhopping guide for German football stadiums.

## Tech stack

- React
- Vite
- TypeScript
- Leaflet
- React Leaflet
- OpenStreetMap

## Getting started

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Current MVP

- Interactive Germany map
- Stadium markers
- Stadium detail cards
- League filtering
- Capacity filtering
- Sample stadium dataset

## Roadmap

- Region filter
- Visited stadium tracker
- Stadium comparison
- Groundhopping road-trip planner
- More stadiums from Bundesliga, 2. Bundesliga and 3. Liga
